# CSC Grid

An accessible Angular data grid built on the WAI-ARIA grid pattern.

**Live demo:** https://grid-amber-eight.vercel.app/

The demo has seven sections, each showing a different set of features: Basic
usage, Advanced features, Editable, Simplified editable, Simplified editable
(selective), Expandable, and All features.

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:4200.
